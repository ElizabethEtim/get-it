# Get It — Property & Item Rental Marketplace

**Get It** is a modern, high-conversion web application designed to simplify property management, housing rentals, and item listings across Calabar, Nigeria. Inspired by sleek, card-based platforms like Airbnb, Get It connects property owners and renters directly through a clean, intuitive interface.

---

## 🚀 Key Features

* **Card-Based Listing Grid:** Clean display of rental listings with high-density images, pricing details, and category tags.
* **Streamlined Post Workflow:** A dedicated submission form (`Post.js`) with two-column input grids and visual upload dropzones.
* **Global Dynamic Footer:** Integrated site-wide footer with direct call (`tel:`) and email (`mailto:`) action icons, legal pages, social links, and dynamic copyright year.
* **Call-To-Action Banners:** Strategic conversion sections encouraging property owners to list items.
* **Responsive Layout:** Optimized for mobile phones and desktop displays using custom CSS Flexbox and Grid layout principles.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React.js

* **Styling & UI:** Custom CSS3 (Flexbox & CSS Grid)
